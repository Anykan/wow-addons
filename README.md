# WoW Addons

A collection of independent World of Warcraft addons. Each addon lives in its own folder and can be installed separately.

## Structure

```
wow-addons/
├── AddonName/
│   ├── AddonName.toc       # Addon metadata (version, dependencies, files)
│   ├── AddonName.lua       # Main entry point
│   └── README.md           # What this addon does
└── ...
```

## Installation

1. Copy the addon folder (e.g. `MyAddon/`) into your WoW AddOns directory:
   ```
   World of Warcraft\_retail_\Interface\AddOns\
   ```
2. Restart WoW or reload the UI (`/reload`).
